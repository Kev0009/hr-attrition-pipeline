# hr-attrition-pipeline

Analyse de l'attrition des salariés à partir du jeu de données IBM HR Analytics (1 470 salariés, 35 variables).

## Premiers constats
- Taux d'attrition global : environ 16 %
- Départements les plus touchés : Ventes (21 %) et RH (19 %), contre 14 % en R&D
- Heures supplémentaires : 30,5 % de départs contre 10,4 % sans heures sup
